Компоненти / Картки й списки

Малий компонент

Статус-піґулка

Мала піґулка для вузького набору станів життєвого циклу — заявки й оголошення, не сигнал довіри.

.status-pill.status-pill--success.status-pill--rejected

Анатомія

Три стани того самого класу — нейтральний, успіх, відхилено.

очікує Активне відхилено
  1. Нейтральна піґулка(.status-pill) — тло --bg-neutral, приглушений текст: типовий стан «очікує», «Зайнято».
  2. Модифікатор успіху(.status-pill--success) — колір --color-action, вага 700: той самий кобальтовий голос, що й ціна та CTA, для означеного позитивного результату.
  3. Модифікатор відхилення(.status-pill--rejected) — приглушений колір з перекресленням через text-decoration-color, не рамкою: --border-default невидимий у темній темі, тому колір лягає на текст.

Варіанти й розміри

Ті самі три стани у двох реальних контекстах.

my-listings — активне / зайняте

Активне Зайнято

applications — очікує / перенесено в чат / відхилено

очікує перенесено в чат відхилено

Стрілка-шеврон — необов'язковий елемент усередині --success, показує перехід у чат, не окремий модифікатор.

Коли вживати

Статус-піґулка вживається рівно у двох місцях: стан заявки «Хочу познайомитись» у applications («очікує» → «перенесено в чат» або «відхилено») і зайнятість оголошення в my-listings («Активне» / «Зайнято»). Це вузький перелік іменованих станів життєвого циклу, не універсальний ярлик — для довільних фактів чи характеристик кімнати призначені факти й чипи. Success-модифікатор зарезервований для означеного позитивного результату («Активне», «перенесено в чат»), а не для будь-якого «хорошого» стану.

applications — очікує / перенесено / відхилено my-listings — активне / зайнято

Правило і антиправило

Так
перенесено в чат

--success для реального результату життєвого циклу — заявку прийнято, оголошення активне. Кобальт тут означає той самий «дія/результат», що й ціна.

✕ Ні
очікує

Показувати статус життєвого циклу через .badge. Обидва — малі округлі піґулки, але означають різне: бейдж каже «ця людина чи кімната верифікована», статус-піґулка каже «ця конкретна заявка чи оголошення в стані X». Змішування розмиває єдиний сигнал, який DESIGN.md вимагає завжди читати як довіру й нічого більше.
