# Handoff-карта активного UI

## Межі й порядок джерел істини

Ця карта охоплює тільки **20 активних екранів** з
[`wireframes/_screens.md`, «Крок 09 — відбір ключових 20 екранів»](../wireframes/_screens.md).
Вона не є специфікацією CSS або копією текстів: для точного селектора, значення токена чи
рядка переходьте до першоджерела, наведеного в клітинках.

1. [`voice.md`](../voice.md) — джерело істини для голосу, словника, звертання та назв дій.
2. [`wireframes/microcopy.md`](../wireframes/microcopy.md) — джерело істини для **точного
   рядка** на кожному екрані й у кожному його стані. Позначка `система` / `користувач` у його
   таблиці визначає походження тексту.
3. [`design-system/tokens.css`](../design-system/tokens.css), блок `SEMANTIC — ролі кольору`
   і primitive-блоки вище нього — джерело токенів. Стрілка в карті означає фактичну
   прив'язку semantic-токена до primitive.
4. [`design-system/components/manifest.txt`](../design-system/components/manifest.txt) — склад
   зібраної дизайн-системи; названі нижче CSS-файли — точне джерело селекторів і повного набору
   токенів компонента.

Усі активні екрани використовують спільну оболонку: `base.css` (`.app` та архетип),
`header.css`, `search.css`, `tabbar.css` і `text.css`. Її токени:
`--bg-page → --cream-200`, `--text-primary → --ink-900`,
`--text-muted → --ink-500`, `--bg-navbar → --olive-600`,
`--on-navbar → --cream-150`; геометрія — `--space-*`, `--size-*`, `--radius-*`,
`--container-*`, `--bp-*`. Повні правила: [`base.css`](../design-system/components/base.css),
[`header.css`](../design-system/components/header.css),
[`tabbar.css`](../design-system/components/tabbar.css).

## Стани та архів

Для кожного сімейства стан `empty`, `error` або `loading` не створює нової компонентної
системи: він використовує вказані `state.css`, `banner.css` або `skeleton.css` у межах того ж
екрана. Які саме стани існують, фіксує [`wireframes/_screens.md`](../wireframes/_screens.md),
а не ця карта.

Поза активним контуром лежать тільки файли `wireframes/_archive/`:
`privacy-settings`, `blocked`, `account`, `report`, `photo-viewer`, `support`, `legal`,
`recovery` (включно з їхніми станами). Повний перелік, причина відбору та важлива ремарка, що
їхній юридичний/інфраструктурний статус не скасовано, —
[`wireframes/_screens.md`, «Архів — 8 екранів»](../wireframes/_screens.md).
