Базовий компонент

Поле форми

Підпис, поле вводу й кастомний select одного тону — без рамки, лише зсув паперу відрізняє поле від фону.

.field.field > label.cap.fsel

Анатомія

Три поля одного `.field`-блоку: текстовий інпут, textarea й окремий `.fsel` — кастомний select.

  1. Підпис(.field > label / .cap) — 11px, uppercase, --text-muted: називає поле, не декорує його.
  2. Поверхня полятло --bg-surface (paper-2, світліше за канвас), без рамки, радіус 12px, висота 48px для інпуту й select — той самий механізм глибини, що й у карток.
  3. Textareaта сама поверхня, мінімальна висота 96px, вертикальний resize.
  4. Кастомний select(.fsel) — нативний select прогресивно покращується до button/listbox, але лишається джерелом form-значення й change.

Мікровзаємодія

Перейди у поле Tab або клацни в нього: кільце фокуса дає відповідь, куди саме зараз піде введення.

Контур фокуса зʼявляється за --dur-fast та --ease-standard, без руху самого поля й без зміни розкладки форми.

У кастомному select список зʼявляється за --dur-base та --ease-enter: це звʼязок між натиснутою кнопкою і тимчасовим списком значень.

Коли вживати

.field — стандартна обгортка для будь-якого текстового введення в системі: від входу й верифікації телефону/коду до створення оголошення кімнати, скарги, звернення в підтримку й редагування профілю. .fsel прогресивно покращує наявний select у button/listbox: опції не дублюються в HTML, нативне поле лишається джерелом form-значення та події change. Без JavaScript це звичайний select. Обидва компоненти читають той самий візуальний закон полів: тло --bg-surface, без рамки, радіус 12px.

Правило і антиправило

Так

Жодне поле — ні інпут, ні textarea, ні .fsel — не має рамки. Глибина сигналізується лише зсувом тону --bg-surface над канвасом, так само, як у картки.

✕ Ні

Повертати рамку .fsel, «бо це список і має виглядати клікабельним». DESIGN.md фіксує саме цю спробу 2026-07-24 і скасовує її: .fsel був єдиним винятком, скопійованим зі старого чернетки — «той самий компонент має виглядати однаково всюди».

Адаптив у макетах

Поля лінійних форм свідомо лишаються читабельною колонкою на всіх ширинах. Ширший екран додає простір навколо кроку, а не перетворює інпут, select чи textarea на надто довгий рядок.
